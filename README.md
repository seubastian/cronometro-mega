# 🎰 Cronômetro Oficial - Mega da Virada 2025 🚀

Este é o cronômetro oficial de contagem regressiva para o sorteio da **Mega da Virada 2025**, desenvolvido exclusivamente para os membros do grupo **Palpite Quente VIP**.

## 🎯 Objetivo
Manter a comunidade alinhada e informada sobre o tempo exato que resta para o sorteio mais esperado do ano, utilizando o horário oficial de Brasília-DF.

## 🧠 Como usar no seu Grupo de WhatsApp:
1. **Aceda ao Link:** Clique no link do Web App hospedado no Streamlit.
2. **Visualize em Tempo Real:** O cronômetro atualiza-se segundo a segundo.
3. **Compartilhe:** Ao partilhar este link no grupo, aguarde a pré-visualização carregar para que todos vejam o destaque do sorteio.
